# story — 어린이 애니메이션 기획 저장소

아이들을 위한 애니메이션의 **세계관, 등장인물, 시나리오**를 구체화하는 저장소입니다.
여기서 확정된 문서는 이후 클로드 디자인에서 불러와 비주얼(캐릭터 시트, 배경, 스토리보드) 제작의 원천 자료로 사용됩니다.

## 저장소 구조

```
story/
├── bible.md              # 스토리 바이블 — 모든 판단의 기준 (가장 먼저 채울 문서)
├── characters/           # 등장인물 (캐릭터 1명 = 파일 1개)
│   ├── README.md         # 캐릭터 목록 인덱스
│   └── _template.md      # 캐릭터 시트 템플릿
├── scenarios/            # 시나리오 (에피소드 1편 = 파일 1개)
│   ├── README.md         # 에피소드 목록 인덱스
│   ├── ideas.md          # 로그라인(한 줄 아이디어) 백로그
│   └── _template.md      # 에피소드 시나리오 템플릿
└── design/               # 비주얼 방향 (클로드 디자인 연동용)
    └── style-guide.md    # 아트 스타일 가이드
```

## 작업 순서

1. **`bible.md`** — 대상 연령, 톤, 세계관, 에피소드 형식을 먼저 확정합니다.
   캐릭터와 시나리오의 모든 판단은 이 문서를 기준으로 합니다.
2. **`characters/`** — `_template.md`를 복사해 캐릭터를 한 명씩 만듭니다.
   주인공 → 조력자 → 감초/대립 캐릭터 순서를 권장합니다.
3. **`scenarios/ideas.md`** — 에피소드 아이디어를 로그라인으로 자유롭게 쌓습니다.
4. **`scenarios/`** — 괜찮은 로그라인만 골라 `_template.md` 형식의 에피소드 파일로 발전시킵니다.
5. **`design/style-guide.md`** — 캐릭터가 어느 정도 모이면 비주얼 방향을 정리합니다.

## 문서 상태 표기

모든 캐릭터·에피소드 문서는 머리말에 상태를 표기합니다.

| 상태 | 의미 |
|------|------|
| `초안` | 작성 중, 자유롭게 수정 가능 |
| `검토중` | 내용은 다 찼고 다듬는 중 |
| `확정` | 클로드 디자인에서 사용해도 되는 버전 |

`확정` 문서를 고치면 관련된 다른 문서(등장 에피소드, 관계된 캐릭터)도 함께 확인합니다.
