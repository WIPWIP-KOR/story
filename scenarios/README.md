# 시나리오

에피소드 1편당 파일 1개를 만듭니다. 흐름은 다음과 같습니다.

1. [`ideas.md`](ideas.md)에 로그라인(한 줄 아이디어)을 자유롭게 쌓는다.
2. 발전시킬 아이디어를 골라 [`_template.md`](_template.md)를 복사해
   `ep<번호>-<제목>.md`로 저장한다. (예: `ep01-잃어버린-모자.md`)
3. 시놉시스 → 씬 구성 → 대본 순서로 템플릿의 섹션을 위에서부터 채운다.
   한 번에 대본까지 쓰지 말고 단계마다 검토한다.
4. 아래 표에 한 줄 추가하고, 등장 캐릭터 파일의 "등장 에피소드" 목록도 갱신한다.

## 에피소드 목록

| 번호 | 제목 | 유형 | 교훈 주제 | 로그라인 | 상태 |
|------|------|------|----------|---------|------|
| 01 | [등껍질 소동](ep01-등껍질-소동.md) | 일반 | 남의 물건은 허락받고 만지기 | 삼남매가 낮잠 자는 느루의 등껍질을 몰래 떼어 놀다가 집안이 뒤집힌다 | 확정 |
| 02 | [사라진 케이크](ep02-사라진-케이크.md) | 일반 | 거짓말하지 않기, 솔직하게 말하기 | 케이크를 망친 삼남매의 "고양이가 그랬어요" 거짓말이 점점 커진다 | 초안 |
| 03 | [장난감들의 가출](ep03-장난감들의-가출.md) | 일반 | 어지른 것 스스로 정리하기 | 장난감 나라의 장난감들이 "이런 집에서는 못 살겠다"며 이삿짐을 싼다 | 초안 |

- **유형**: `일반`(교훈 대상: 아이) / `부모`(교훈 대상: 부모) / `놀이`(교훈 없음)
- 부모 회차는 시즌당 소수만 둡니다 (bible.md 5번 참고).

- 표의 제목은 에피소드 파일로 링크합니다. 예: `[잃어버린 모자](ep01-잃어버린-모자.md)`
- 에피소드 번호는 제작 순서일 뿐, 방영 순서는 나중에 따로 정할 수 있습니다.
