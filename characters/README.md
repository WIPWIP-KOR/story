# 등장인물

캐릭터 1명당 파일 1개를 만듭니다. 새 캐릭터는 [`_template.md`](_template.md)를 복사해서
`<이름>.md`로 저장하고, 아래 표에 한 줄 추가하세요.

- 표의 이름은 캐릭터 파일로 링크합니다. 예: `[또리](또리.md)`

## 이 작품의 캐릭터 구성 (bible.md 기준)

1. **거북이 보모** — 나이 많은 거북이 신사. 마법의 원천은 마법 등껍질.
   깔끔하고 점잖은 신사 이미지. 캐릭터 파일에서 정할 것: 이름, 말투(신사다운
   말버릇), 등껍질 마법의 발동 방식과 한계, 화내지 않는 방식의 개성.
2. **삼남매** (말썽쟁이) — 이한(7살) · 이이상(5살) · 이세상(3살).
   말썽은 개인기가 아니라 **셋이 함께 저지르는 공동 사고**입니다 (bible.md 3번).
   대신 공동 말썽 안에서 맡는 역할이 서로 다릅니다:
   계획(이한) → 실행(이이상) → 뜻밖의 방아쇠(이세상).
   나이가 3·5·7살로 분산되어 시청 연령대(3~7세)의 아이들이 각자 자기를 대입할
   캐릭터가 있습니다.
3. **부모** — 반복 조연. 보모의 정체(말하는 거북이, 마법)를 알고 신뢰해서 아이들을
   맡깁니다. 일반 회차에서는 시작(외출·부탁)과 끝(귀가·포옹)을 담당하는 가벼운
   역할이지만, **부모 회차에서는 깨달음을 얻는 주인공**이 되므로 부모도 각자
   성격과 서투른 점을 가진 캐릭터로 설계합니다.
4. 주변 인물(이웃, 아이 친구)은 에피소드 아이디어가 쌓이면서 필요할 때 추가합니다.
