# 등장인물

캐릭터 1명당 파일 1개를 만듭니다. 새 캐릭터는 [`_template.md`](_template.md)를 복사해서
`<이름>.md`로 저장하고, 아래 표에 한 줄 추가하세요.

## 캐릭터 목록

| 이름 | 역할 | 한 줄 소개 | 상태 |
|------|------|-----------|------|
| _(아직 없음)_ | | | |

- **역할** 구분: `주인공` / `조력자`(주인공의 친구·가족) / `감초`(웃음 담당) / `대립`(경쟁자·말썽꾼 — 악당이 아니라 갈등을 만드는 정도)
- 표의 이름은 캐릭터 파일로 링크합니다. 예: `[또리](또리.md)`

## 만드는 순서 권장

1. 주인공 1명 — 작품의 시선이 되는 캐릭터
2. 핵심 조력자 1~2명 — 주인공과 성격이 뚜렷하게 대비되도록
3. 감초·대립 캐릭터 — 에피소드 아이디어가 쌓이면서 필요해질 때 추가
