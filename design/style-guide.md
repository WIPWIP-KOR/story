# 아트 스타일 가이드

> 클로드 디자인에서 이 저장소를 불러올 때 비주얼 방향의 기준이 되는 문서입니다.
> 캐릭터 개별 외형은 각 캐릭터 파일의 "외형" 섹션에 있고, 이 문서는 작품 전체에
> 공통으로 적용되는 스타일만 다룹니다.

- 상태: 검토중

## 전체 그림체

- 둥근 도형 기반의 단순한 2D 카툰. 모든 실루엣은 원과 타원에서 출발한다.
- 굵고 부드러운 외곽선 (진한 갈색 계열 — 검정보다 따뜻하게).
- 플랫한 채색에 은은한 종이 질감 한 겹. 그라데이션과 사실적 음영은 쓰지 않는다.
- 표정은 크고 과장되게: 눈이 얼굴의 중심. 3세도 감정을 즉시 읽을 수 있어야 한다.
- 화면에 글자가 등장할 때(간판, 그림책, 메모)는 한국어로 쓴다 (bible.md 1번).

## 색

- 전체 인상: **볕 잘 드는 오후의 파스텔** — 채도는 중간, 명도는 높게.
  쨍한 원색 대신 크레용으로 칠한 듯한 부드러운 색.
- 기본 무대(집)의 색감: 크림색 벽, 따뜻한 원목 가구, 볕이 드는 노란 창.
- **캐릭터 상징색** (한 화면에 모여도 서로 구분되도록 설계):
  - 느루: 청록(등껍질) + 겨자색(조끼) — 화면의 안정감을 담당하는 색
  - 이한: 파랑 / 이이상: 주황 / 이세상: 분홍 — 삼남매는 원색 계열 파스텔
  - 아빠: 초록 / 엄마: 보라 — 부모는 채도를 한 단계 낮춘 차분한 톤
  - 느루의 청록과 아빠의 초록은 명도·용도가 다르다: 느루는 짙은 청록(teal),
    아빠는 밝은 잎사귀 초록(green)으로 구분한다.
- **마법 연출색**: 등껍질 마법은 항상 **금색 별가루 반짝임** + 육각 무늬 발광.
  마법 장면임을 알리는 시그니처 색으로, 다른 연출에는 금색 반짝임을 쓰지 않는다.

## 비례와 형태 규칙

- 삼남매: 2~2.5등신. 이한 > 이이상 > 이세상 순으로 키 계단.
- 부모: 3등신. 느루: 2.5등신에 등껍질이 실루엣의 절반을 차지하는 둥근 형태.
- 손가락은 4개, 손발은 둥글게. 관절·근육 표현 없음.
- 모든 사물의 모서리는 둥글린다. 뾰족한 것(가위 등)도 끝이 뭉툭하게.

## 배경과 소품

- 배경 디테일은 낮게 — 캐릭터가 항상 주인공. 벽 장식은 3~4개 이내.
- 소품은 실제보다 통통하고 둥글게 과장 (꽃병도 항아리처럼 둥글다).
- 마법 놀이 세계(등껍질이 여는 세계)는 현실 무대보다 채도를 반 단계 올려
  "놀이 시간"임을 색으로 구분한다. 돌아오면 원래 채도로.

## 하지 않을 것

- 날카로운 모서리, 뾰족한 이빨, 사실적인 인체 비례.
- 어두운 그림자, 실루엣만 보이는 연출, 명암 대비가 강한 화면 (공포감 방지).
- 붉은 경고색의 남용 — 빨강은 소품 포인트로만.
- 마법 연출에 번개·폭발·연기 같은 위협적 이펙트. 마법은 언제나 반짝이고 몽글하다.
