# 등장인물

캐릭터 1명당 파일 1개를 만듭니다. 새 캐릭터는 [`_template.md`](_template.md)를 복사해서
`<이름>.md`로 저장하고, 아래 표에 한 줄 추가하세요.

## 캐릭터 목록

| 이름 | 역할 | 한 줄 소개 | 상태 |
|------|------|-----------|------|
| _(아직 없음)_ | | | |

- **역할** 구분: `보모` / `아이` / `가족`(부모 등) / `주변`(이웃, 친구 등 반복 조연)
- 표의 이름은 캐릭터 파일로 링크합니다. 예: `[또리](또리.md)`

## 이 작품에 필요한 구성 (bible.md 기준)

1. **동물 보모 1명** — 마법을 쓰는 이 작품의 중심축. 가장 먼저 확정할 캐릭터.
   동물 종, 마법의 형태(주문·노래·도구), 성격(화내지 않는 방식의 개성)을 정해야
   `bible.md`의 [결정 필요] 항목이 풀립니다.
2. **말썽쟁이 아이 2~3명** — 말썽의 유형이 서로 겹치지 않게 설계합니다.
   예: 고집·떼쓰기형 / 덤벙·어지르기형 / 샘내기·욕심형. 나이 차(예: 6살 언니와
   4살 동생)를 두면 3~7세 시청자가 각자 자기를 대입할 캐릭터가 생깁니다.
3. **부모** — 반복 조연. 이야기의 시작(외출·부탁)과 끝(귀가·포옹)을 담당하는
   정도로 가볍게 설계합니다.
4. 주변 인물(이웃, 아이 친구)은 에피소드 아이디어가 쌓이면서 필요할 때 추가합니다.
